# 适配说明：为什么做这份补丁，它和 playtest 版有什么不同

> **版本 2.0**（2026-11-15 发布）｜ 适配引擎 `release-20250330` ｜ 75 个载荷 ｜ 文本覆盖率 91.7%（2487/2711）

本包是基于 **Janlhin/OpenRA_Simplified_Chinese 1.6.1** 的译文，**重新适配到官方稳定版 `release-20250330`** 的版本。上游 1.6.1 只支持 `playtest-20261026`，直接装到稳定版会出问题，原因见下。

---

## 一、Release 与 Playtest 的区别（官方页面给出的两种构建）

| 维度 | Release（`release-20250330`） | Playtest（`playtest-20261026`） |
|---|---|---|
| 定位 | 官方推荐给**联机对战**的正式版 | 预览版，供玩家尝鲜并反馈问题，用来打磨下一个正式版 |
| 更新节奏 | 稳定，约一年一版 | 频繁，数月内多次快照 |
| 内容 | 功能已冻结、回归测试做过 | 含新功能、新界面、新机制（本次差异里有 `settings-gameplay`、`load-game-browser`、`map-generators`、`Cheats` 面板改名等） |
| 风险 | 低 | 可能有未修缺陷（本次就有 OpenRA#22716 字形线程崩溃） |
| 体积 | Windows 58.43MB | Windows 62.32MB |
| 上游汉化补丁 | ❌ 不兼容 | ✅ 1.6.1 唯一适配 |

**结论**：联机稳定 → 装 Release；跟着上游最新功能走 → 装 Playtest。两者可以各装一份、目录分开、互不干扰。

---

## 二、为什么不能把 1.6.1 直接装到 Release

上游补丁的 208 个载荷里，有一部分是 **playtest 专属**，硬套会出现这些后果：

| 载荷类型 | 数量 | 直接套到 Release 的后果 |
|---|---|---|
| `mod.yaml`（6 个） | 6 | 文件里带 `rules/map-generators.yaml`、`chrome/settings-gameplay.yaml`、`chrome/load-game-browser.yaml`、`RendererConstants`、`MapGrid.TileSize` 删除等 **playtest 引擎才认的字段** → 稳定版加载模组时直接报错 |
| 地图级 `map.ftl` | 134 | 稳定版**确实支持**地图级 fluent（官方自带 12 个 `map.ftl`），但那 12 个只放难度下拉这类**被 yaml 显式按名引用**的键；稳定版的战役简报是 rules.yaml 里的**内联文本**，没有任何地方按 `briefing` 这个名字去找它 → 上游那 134 个只含 `briefing` 的文件放进来不会被取用 |
| `ingame-debug.ftl` | 1 | 稳定版没有 `Cheats` 面板，也没有这个文件 |
| 3 张战役地图 `rules.yaml` | 3 | 上游把 `Briefing:` 的正文换成了 fluent 键名 `briefing`，靠 `map.ftl` 取值。稳定版的地图 yaml 不做这种隐式覆盖，对应的 `map.ftl` 里也没有该键 → 简报会**字面显示 "briefing"** |
| 其余文本 `.ftl` | 39 | 键集是 playtest 的，稳定版缺少其中 723 个键（孤儿键）；直接替换会让稳定版独有的 216 条文案**变成空白或键名** |

## 三、这份补丁是怎么适配的（5 条硬规则）

1. **只以官方 Release 文件为基线**，译文只借用补丁的"值"，结构一律用稳定版自己的。
2. **`.ftl` 做块级合并**：稳定版 2711 条消息**一条不少**地保留，能把译文对上的就地替换，对不上的自动回落英文——不会出现空白或 `!!missing!!`。
3. **占位符校验**：译文里的 `{ $var }` 变量集合与英文不一致的（8 条），强制保留英文，避免运行时空变量。
4. **`mod.yaml` 只改 `Fonts` 段的字体名**（`FreeSans.ttf` → `NotoSansSC-Regular.ttf` 等，共 40 处），playtest 专有字段一个都不引入。
5. **地图文件只做纯文本替换**：3 张地图只换 `CountdownText`，`Briefing` 保持英文，`AlwaysVisible` 等规则字段不动——**不改变任何地图行为**。

## 五、明确不做的事

- **不动 `map.yaml`**：地图 UID = `SHA1(map.yaml + *.bin + *.lua + map.png)`，改了就和没打补丁的玩家对不上，旧录像也读不了。代价是关卡名保持英文。
- **战役简报为何还留英文**：简报正文在稳定版里是 `rules.yaml` 的内联文本，而 `rules.yaml` **不参与地图 UID** —— 也就是说把 140 份中文简报写进去，机制上完全可行（文本已经在补丁里备好了）。
  之所以本版不启用：上游记录过「中文战役简报触发字形线程崩溃」（OpenRA#22716，出在 playtest 的 SpriteFont 新路径，官方为此发了 hotfix DLL）；稳定版是否也受影响，目前只有结构层面的证据、没有实机渲染确认。
  宁可先给一版简报英文但绝不崩的，也不拿 140 份简报去赌。想要简报中文化，可以让本包先跑一轮实测，确认无崩溃后再出 2.1。
- **不改 DLL**：上游 1.6.1 的 `hotfix\` 是给 playtest 修字形线程崩溃的，稳定版没这个缺陷，所以本包不含任何 DLL（不会触发杀软误报游戏程序集）。
- **不碰美术、音频、`.mix`**。

## 七、已知风险

1. 本包由第三方（非上游作者）比对生成，**未经大范围实机验证**；装前请确认引擎版本恰好是 `release-20250330`。
2. 上游引擎升级后（新 Release 发布），请先 `-Mode Restore` 还原，再等新一版适配。
3. 服务器端若有文件校验插件，仍可能判定改文件——所有汉化补丁的共同风险。
