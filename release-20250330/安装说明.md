# OpenRA 简体中文补丁 2.0（适配官方稳定版 release-20250330）

> 第三方社区作品，与 OpenRA 官方项目无隶属关系。只做文本替换，不改游戏逻辑、不改 `.dll`、不联网。

## 一、装之前必须先有游戏本体

这个包**只有译文和字体，没有引擎**。请先安装官方 **稳定版 `release-20250330`**：

- Windows 安装包：<https://www.openra.net/download/>（Windows → Download Release，58.43MB）
- 或 GitHub 便携版：`OpenRA-release-20250330-x64-winportable.zip`（解压即用）

> ⚠ 请**不要**把本补丁装到 `playtest-20261026` 上。上游作者 Janlhin 的 1.6.1 补丁才是给 playtest 做的，两套不要混用。

## 二、安装（三分钟）

1. 把本包解压到一个**纯英文路径**下，例如 `D:\OpenRA_CN_patch`（路径含中文可能让脚本读不到文件）。
2. **完全关闭 OpenRA**（主程序、服务器窗口都要关）。
3. 右键 `setup.ps1` → **使用 PowerShell 运行** → 菜单输入 `1` → 回车。

PowerShell 被策略拦住时，直接双击 `setup.cmd`（内部用 `-ExecutionPolicy Bypass` 调起同一个脚本）。

脚本会先自动找常见安装位置；找不到就让你手动填目录。它做的事：

- 把将被覆盖的原文件**逐字节备份**到 `<游戏目录>\_cn_backup\<时间戳>\`，并写 `backup.json` 记录每个文件的原始 SHA-256；
- 覆盖 67 个文本文件（39 个 `.ftl` + 19 个内容安装器文案 + 2 个创建服务器文案 + 3 个战役分组名 + 3 张战役地图文案 + 1 句任务提示）、6 个 `mod.yaml` 的字体声明；
- 往 `mods\common\` 放两个中文字体（`NotoSansSC-Regular.ttf` / `-Bold.ttf`），**原 FreeSans 字体不删**。

合计 199 个文件。

装在 `C:\Program Files` 下会弹一次 UAC，需要管理员权限。

## 三、命令行用法

```powershell
.\setup.ps1 -Mode Install                       # 安装（自动找目录）
.\setup.ps1 -Target "D:\OpenRA" -Mode Install   # 指定目录
.\setup.ps1 -Mode Install -DryRun               # 只预览，不写文件
.\setup.ps1 -Mode Restore                       # 用最新备份还原英文
.\setup.ps1 -Mode Verify                        # 校验是否装全（退出码 0 = 完好）
```

## 四、还原英文

重跑 `setup.ps1` → 菜单 `2`。它按 `backup.json` 把原文件逐个放回，并删除本补丁新增的字体文件。
备份目录不会自动删除，确认没问题后可以自己删掉 `_cn_backup`。

## 五、常见问题

**界面还是英文？**
装错目录了（多套一层 `mods\mods`）。跑 `-Mode Verify` 看“已安装且完好”是不是等于载荷总数。

**中文显示成方块？**
`mods\common\` 下必须同时存在 `NotoSansSC-Regular.ttf` 和 `NotoSansSC-Bold.ttf`。缺一个就 `-Mode Install` 重装。

**会影响联机或存档吗？**
不改地图数据（`map.yaml` 一律没动），联机地图 UID 不变；存档在 `%APPDATA%\OpenRA`，补丁不碰。
但服务器若装了文件校验插件，仍可能判定你改过文件——这是所有汉化的共同风险。

**杀毒软件报毒？**
安装器是未签名脚本 + 两个字体文件，部分杀软会提示。本包**不含任何 DLL**，比 1.6.1 线（playtest）那版干净。

**进「战役」点任务闪退？**
那是 OpenRA 官方 playtest 引擎的字形线程缺陷（OpenRA#22716），**只发生在 playtest-20261026**。稳定版 release-20250330 不存在该问题，所以本包不需要热修 DLL。

## 六、已知限制

1. **战役简报已全部中文化**（127 张在稳定版里有简报的地图）。稳定版的简报正文内联在各地图的 `rules.yaml` 里，而 `rules.yaml` **不参与地图 UID**——不影响联机、不影响旧录像，所以直接替换正文是安全的。另有 13 张地图在稳定版里没有对应目录（那是 1.6.1 线独有的地图），无需处理。
   尚未验证的只有**渲染**：1.6.1 线曾出现中文简报触发的字形线程崩溃（OpenRA#22716），稳定版是否有同样问题还没实机确认。若进战役就崩，用菜单 `2` 还原即可，并把现象告诉我。
2. **战役关卡名仍是英文**（如 `Allies 01`），原因同上（地图元数据在 `map.yaml` 里）。
3. **作弊面板（Cheats）没有中文**：稳定版仍是旧的 `Debug` 面板，上游 `Cheats` 那套文案在这里没有对应位置。
4. **234 条文案仍是英文**，逐条清单见随附的 `未译条目清单.csv`（含归类）：216 条是 1.6.1 线里根本没有这些键（地图编辑器、`Debug` 面板等稳定版独有文案）；9 条是 `OpenRA`/`ID`/`APM` 这类符号缩写，本就不该译；9 条是译文变量名与稳定版不一致，强行套用会显示成字面 `{ $count }`。
