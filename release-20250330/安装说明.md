# OpenRA 简体中文补丁 2.0.0（适配官方稳定版 release-20250330）

> 第三方社区作品，与 OpenRA 官方项目无隶属关系。只做文本替换，不改游戏逻辑、不改 `.dll`、不联网。

## 一、装之前必须先有游戏本体

这个包**只有译文和字体，没有引擎**。请先安装官方 **稳定版 `release-20250330`**：

- Windows 安装包：<https://www.openra.net/download/>（Windows → Download Release，58.43MB）
- 或 GitHub 便携版：`OpenRA-release-20250330-x64-winportable.zip`（解压即用）

> ⚠ 请**不要**把本补丁装到 `playtest-20261026` 上。那是 playtest 线补丁的目标引擎，两套不要混用。

## 二、安装（三分钟）

1. 把本包解压到一个**纯英文路径**下，例如 `D:\OpenRA_CN_patch`（路径含中文可能让脚本读不到文件）。
2. **完全关闭 OpenRA**（主程序、服务器窗口都要关）。
3. 两种入口任选其一：
   - **双击 `setup.cmd`**：纯批处理，不需要 PowerShell，也不受执行策略限制；
   - **右键 `setup.ps1` → 使用 PowerShell 运行**：中文菜单，`1` 安装 / `2` 还原 / `3` 校验 / `4` 预演。

安装器做的事：

- 把**将被覆盖的原文件**逐个备份到 `<游戏目录>\_zhcn-backup\<时间戳>\`（只备份这 197 个，约 0.7MB，不整棵拷 `mods\`）；
- 先放两个中文字体到 `mods\common\`（`NotoSansSC-Regular.ttf` / `-Bold.ttf`），**原 FreeSans 不删**；
- 再覆盖 197 个文本文件（39 个 `.ftl` + 19 个内容安装器文案 + 6 个 `mod.yaml` 的字体声明 + 12 张地图的难度文案 + 127 张地图的战役简报 + 若干创建服务器 / 战役分组文案）；
- 每覆盖一个文件都按 `bin\manifest.json` 里的 SHA-256 复核，装完再整体报告成功 / 失败数量。

合计 **199** 个文件（197 文本 + 2 字体）。

装在 `C:\Program Files` 下会弹一次 UAC，需要管理员权限。

## 三、命令行用法

PowerShell 入口（`setup.ps1` 只做转发，逻辑在 `bin\install.ps1`）：

```powershell
.\setup.ps1                                  # 打开菜单
.\setup.ps1 -Target "D:\OpenRA"              # 直接装（省略 -Target 则自动探测）
.\setup.ps1 -Uninstall                       # 用最新备份还原英文
.\setup.ps1 -Verify                          # 校验「还有没有中文残留」，0 = 已干净
.\setup.ps1 -DryRun                          # 只预览，不写任何文件
.\setup.ps1 -Target "D:\OpenRA" -Force       # 跳过引擎版本检查
```

纯 CMD 入口（`setup.bat` 与 `setup.cmd` 内容相同，哪个能双击就用哪个）：

```bat
setup.cmd "D:\OpenRA" /install
setup.cmd "D:\OpenRA" /restore
setup.cmd "D:\OpenRA" /verify
setup.cmd "D:\OpenRA" /install /force
set OPENRA_NOPAUSE=1
```

最后一行是给脚本 / 计划任务用的：设了 `OPENRA_NOPAUSE=1` 就不会在结束时等你按键。

## 四、还原英文

重跑 `setup.ps1` → 菜单 `2`（或 `-Uninstall`、`/restore`）。它按备份把原文件逐个放回，并删除本补丁新增的字体。
备份目录**不会自动删除**——确认游戏正常后，自己删掉 `<游戏目录>\_zhcn-backup` 即可。删除后与官方原版逐字节一致。

## 五、常见问题

**界面还是英文？**
先看安装器报的成功数量是不是 199。若装到了 `mods\mods` 这种多套一层的目录，会一个文件都覆盖不上。

**`-Verify` 报「仍在位」？**
它的语义是「汉化是否已卸载干净」：装完立刻跑当然还有 197 个中文在位，退出码 1 属正常。还原之后再跑才应该是 0。

**中文显示成方块？**
`mods\common\` 下必须同时存在 `NotoSansSC-Regular.ttf` 与 `NotoSansSC-Bold.ttf`。缺一个就重装一次。

**会影响联机或存档吗？**
地图 `map.yaml` 一律没动，联机地图 UID 不变；`rules.yaml` 只改简报正文，而它不参与 UID，所以旧录像也能读。存档在 `%APPDATA%\OpenRA`，补丁不碰。但服务器若装了文件校验插件，仍可能判定你改过文件——这是所有汉化的共同风险。

**杀毒软件报毒？**
安装器是未签名脚本 + 两个字体文件，部分杀软会提示。本包**不含任何 DLL**，比 playtest 线那版干净。

**进「战役」点任务闪退？**
先用菜单 `2` 还原：若还原后不再崩，就是中文渲染的问题（playtest 线出过 OpenRA#22716 的字形线程崩溃）；还原后照旧崩，则是引擎本身的问题，与本补丁无关。

## 六、已知限制

1. **战役简报已全部中文化**（127 张在稳定版里有简报的地图）。简报正文内联在各地图的 `rules.yaml` 里，而 `rules.yaml` **不参与地图 UID**——不影响联机、不影响旧录像。另有 13 张地图在稳定版里没有对应目录（那是 playtest 线独有的地图），无需处理。
   尚未验证的只有**渲染**：playtest 线曾出现中文简报触发的字形线程崩溃（OpenRA#22716），稳定版是否有同样问题还没实机确认。
2. **战役关卡名仍是英文**（如 `Allies 01`），因为在地图 `map.yaml` 里，改它会改变地图 UID。
3. **作弊面板（Cheats）没有中文**：稳定版仍是旧的 `Debug` 面板，`Cheats` 那套文案在这里没有对应位置。
4. **234 条文案仍是英文**，逐条清单见随附的 `未译条目清单.csv`（含归类）：216 条是 playtest 线里根本没有这些键（地图编辑器、`Debug` 面板等稳定版独有文案）；9 条是 `OpenRA`/`ID`/`APM` 这类符号缩写，本就不该译；9 条是译文变量名与稳定版不一致，强行套用会显示成字面 `{ $count }`。
