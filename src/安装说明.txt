 ① 一键安装：PS1 与 BAT/CMD 二选一
--------------------------------------------------------------

  前提：Windows 10 / 11；先关掉 OpenRA 三个 exe 的窗口；zip 解压到英文路径（如
  D:\OpenRA_CN）。

  A. PS1 路线（PowerShell 可用时，推荐）

  1. 右键 setup.ps1 → 使用 PowerShell 运行
  2. 菜单输入 1 → 回车
  3. 按提示启动游戏

  菜单：1 安装 · 2 还原英文 · 3 校验是否卸干净

  安装器自动完成：定位游戏目录 → 备份 → 覆盖 208 个文本 → 部署两个中文字体 →
  逐文件 SHA-256 校验。
  备份在 <游戏目录>\_zhcn-backup\<时间戳>\，还原靠它；卸载完成后可安全删除。

  参数                         作用
  ---------------------------------------------------------------
  -Target "D:\Games\OpenRA"    指定游戏目录（自动探测失败时）
  -Uninstall                   还原英文
  -Verify                      校验是否卸干净
  -DryRun                      只预览要改哪些文件，不写入任何文件
  -FontPath "D:\yourfont.ttf"  换字体
  -Yes                         全部按“是”处理

  B. 纯 BAT / CMD 路线（PS1 用不了时）

  适用：公司电脑用组策略禁用了 PowerShell、系统被精简掉 PS、执行策略锁死，
  或双击 .ps1 只弹出记事本。这套入口完全不依赖 PowerShell，只用系统自带的
  cmd.exe / certutil.exe / robocopy.exe。

  1. 双击 setup.bat；如果 .bat 被改过关联或被安全软件拦，双击 setup.cmd
  （两者内容完全相同，只是扩展名不同）。
  2. 菜单输入 1 → 回车：定位游戏目录 → 备份 mods → 先放字体 → 覆盖 208 个文
     本
  → 用 certutil 逐文件 SHA-256 校验。
  3. 菜单 2 还原英文，3 校验是否卸干净（退出码 0 = 干净，1 = 仍有残留）。
  4. UAC 弹窗点「是」（装在 Program Files 时才会弹；自建目录不会）。

  也可以带参数直接跑，便于脚本调用：

    setup.bat "D:\Games\OpenRA" /install
    setup.bat "D:\Games\OpenRA" /restore
    setup.bat "D:\Games\OpenRA" /verify

  屏幕提示是英文：cmd.exe 在中文代码页下会把中文批处理行拆坏，所以脚本刻意只用
  ASCII，中文步骤以本文为准。常见提示对照：

  · [1/3] Backing up mods ...
      正在备份 mods

  · [2/3] Deploying fonts and 208 texts ...
      正在部署字体与文本

  · [3/3] Checked 210 files, 0 failed.
      210 个条目全部校验通过（208 文本 + 2 字体）

  · [OK] Chinese patch installed.
      装好了，可以启动游戏

  · Result: clean, English originals.
      已卸干净

  它的备份目录是 <游戏目录>\_zhcn-backup\0001、0002…（4 位递增序号，取编号最大
  的那份），
  与 PS1 路线的时间戳备份互不干扰；还原时会自动跳过「装完又装一次」产生的假备
  份。
  bin\files.sha256 是它的部署清单（210 行：哈希 / 包内源路径 / 游戏目录相对路
  径），
  由 manifest.json 自动生成，不要手改。

  ※ 引擎版本不匹配时纯 CMD 路线会直接中止，不会弹交互确认；确认无误要强行安
    装，

  ※ 加第三个参数：setup.bat "D:\Games\OpenRA" /install /force。

 ② 让 AI 助手安装
--------------------------------------------------------------

  把下面整段交给能在你电脑上执行命令的 AI 助手（装在 Program Files 需要管理员
  权限，它可能要你点一次 UAC）：

    把这个目录里的 OpenRA 简体中文汉化补丁装到我电脑上的 OpenRA。
    1) 读 <游戏目录>\mods\ra\mod.yaml 的 Version，必须为 playtest-20261026；否则停下并报告当前版本。
    2) 把整个 <游戏目录>\mods 备份到 <本包目录>\_manual-backup\<时间戳>\。
    3) 把本包 files\mods\ 下的内容按同名路径覆盖到 <游戏目录>\mods\。
    4) 把本包 fonts\ 的 NotoSansSC-Regular.ttf 与 NotoSansSC-Bold.ttf 复制到 <游戏目录>\mods\common\。
    5) 不要改任何 map.yaml，也不要改 mod.yaml 里的字体名（包里已改好）。
    6) 完成后报告：208 个文件是否到位、两个字体是否存在、mod.yaml 的 Version 是否仍为 playtest-20261026。

  如果它没有管理员权限，让它把第 3、4 步交给你手动执行。

 ③ 手动安装
--------------------------------------------------------------

  适用：两套一键入口都不想用（PS1 与纯 CMD 都不跑）。没有任何校验，四步顺序不
  能错。

  第 1 步：备份

  把 <游戏目录>\mods 整个复制到别处（约 100 MB）。

  第 2 步：先放字体

  把本包 fonts\ 两个文件复制到 <游戏目录>\mods\common\：
  NotoSansSC-Regular.ttf、NotoSansSC-Bold.ttf

  第 3 步：覆盖文本

  把本包 files\mods\ 的全部内容按同名路径覆盖到 <游戏目录>\mods\
  （208 个，其中 12 个是新增：common\fluent\ingame-debug.ftl 与 11 个
  d2k\maps\*\map.ftl）

  第 4 步：启动游戏

  按提示选 RedAlert.exe / TiberianDawn.exe / Dune2000.exe。

  ※ 顺序反了会怎样：先覆盖文本、后放字体 → mod.yaml 已指向 NotoSansSC 但文件
    不存在，引擎直接报错退出（不是变方块）；只放字体、不覆盖文本 → 能进游戏，
    但界面仍是英文。

  自检：<游戏目录>\mods\common\ 下应同时有 NotoSansSC-Regular.ttf、
  NotoSansSC-Bold.ttf 与 fluent\ingame-debug.ftl。

  还原：把第 1 步备份的 mods 覆盖回去，再删掉那两个 NotoSansSC-*.ttf。

  ### 可选：应用引擎热修（playtest-20261026 专用的闪退修复）

  汉化文本本身不影响游戏逻辑，但上游 playtest-20261026 有一个引擎缺陷：中文战
  役简报会让游戏在
  「战役」界面点选任务时闪退。1.6.1 起本包附带一个可选热修（hotfix\ 目录），它
  只改两个引擎程序集，
  不碰文本、美术与音频。

  什么时候才需要：用 playtest-20261026 + 中文界面 + 进「战役」点任务会闪退。其
  余情况不用装。

  怎么用：关掉所有 OpenRA 窗口 → 双击 hotfix\apply-hotfix.bat
  （.bat 被拦就双击 hotfix\apply-hotfix.cmd），在 UAC 弹窗点「是」。
  这两个入口是纯批处理，不依赖 PowerShell、屏幕提示为英文，详见
  hotfix\README.md。

  PowerShell 可用的机器也可以右键 hotfix\apply-hotfix.ps1 →「使用 PowerShell
  运行」，
  装在别处用 -Target "D:\Games\OpenRA"（纯 CMD 版则把目录作为第一个参数传入）。

  脚本会先对两个 DLL 统一做哈希预检（只接受官方原版或已打补丁两种状态，任一不
  合格就
  整体中止、零文件改动），备份原版为 *.orig-20261109 后再覆盖并复验；
  要还原就双击 hotfix\rollback-hotfix.bat / .cmd（或运行 rollback-hotfix.ps1）。

  不想装热修也可以：卸载补丁改用英文界面即可避开这个崩溃。上游修复后，本热修会
  随下个版本移除。

 ④ 问题排查
--------------------------------------------------------------

  · 界面全是方块
      字体没生效。mods\common\ 缺 NotoSansSC-*.ttf，或 mod.yaml 的字体名对不上；
      手动安装的回到第 2 步

  · 界面仍是英文
      文本没覆盖成功。确认盖的是 mods\ 而不是 mods\mods\（多套一层最常见）

  · 卸载后仍是中文
      还原用错了备份。重跑选 2；仍不行用 -Uninstall -Backup <备份目录名> 指定

  · 启动即报错 / 闪退
      多半是“覆盖了文本但没放字体”，照第 2 步补齐两个字体

  · 进「战役」点任务就闪退
      上游引擎缺陷（playtest-20261026）：中文简报首次上屏时字形在后台线程生成，
      与渲染线程争用同一份图集。本补丁只换文本不换引擎，无法从根上消除。已上报
      <https://github.com/OpenRA/OpenRA/issues/22716>。1.6.1 起包内附带可选热
      修：关掉游戏后双击 hotfix\apply-hotfix.bat 或 .cmd（纯 CMD，不依赖 PS；
      详见第 ③ 步补充说明）；不想装就卸载补丁改用英文界面

  · 战役界面「难度」是灰的、点不动
      该任务本身没有难度选项（上游设计，如红警 01、10b 与苏军 01/02a/02b），不
      是补丁问题；换一个有难度的任务即可

  · 出现 label-xxx 键名
      补丁与游戏版本不匹配（游戏升级过）。卸载后换对应新版本的补丁

  · 影响联机 / 存档吗
      不改地图数据，联机与旧录像兼容；存档在 %APPDATA%\OpenRA，补丁不碰。服务
      器若装文件校验插件，理论上可能判定为改文件

  · 杀毒软件报毒
      安装器是未签名脚本（PS1 或纯 CMD）。不放心就走手动安装，效果完全相同；
      PS1 跑不起来请用纯 CMD 入口
